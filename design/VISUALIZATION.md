# 可视化

可视化是产品的主要信息语言，不是结果页装饰。选择渲染器的原则：**通用统计图用 ECharts，独特视觉用 SVG 手写**，不为统一而牺牲表达。

| 模块 | 作用 | 渲染 |
| --- | --- | --- |
| A 人格雷达图 | 16 维向量（核心 8 / 完整 16） | ECharts radar |
| B 你 vs 主神格 | 解释“为什么是它” | ECharts radar（双序列） |
| C 神格轨道图 | YOU 为中心的四神格关系 | SVG |
| D 内在神战 | 最强张力对，适合截图 | SVG |
| E 神格构成 | Top 5–7 构成 | ECharts 横向 bar（非饼图） |
| F 觉醒轨迹 | Dormant → Awakened → Overawakened → Fallen | SVG 横向轴 |
| G 人格星图 | 聚合簇的星座美学 | SVG |
| H 人格张力矩阵 | 手机快速理解 | SVG / CSS 双极条 |

## A 人格雷达图

两种模式：核心维度（由 `dimensions.json` 的 `core: true` 自动选出 8 个）、完整维度（16 个）。16 维时标签旋转、外置，避免重叠。ECharts 用 SVG renderer 保证清晰与可访问性。

## B 你 vs 主神格

同一雷达图两条序列。图下方必须自动生成两行文本：**最接近的维度** 与 **最大差异维度**，并解释这些接近之处为什么不是泛泛的“反叛/聪明”：

> 你和普罗米修斯最接近的地方不是反叛，而是创造、改造世界，以及对既定边界的低服从度。

## C 神格轨道图

视觉编码：距离 = 人格接近度；大小 = 匹配强度；连线 = 关系类型（实线协同 / 虚线张力 / 双线镜像 / 断裂线冲突 / 细灰线压制）。中心固定为 YOU，四角标注角色名（主 / 副 / 阴影 / 隐藏）。窄屏退化为纵向列表 + 连线说明，不缩小到不可读。

## D 内在神战

左右两个原型，中间四条对比轴（例如“反抗权威 ↔ 建立权威”），条长表示倾向强度。中央给出核心矛盾问句。整体按 4:5 比例排版，保证手机截图完整。

## E 神格构成

横向条形图而非饼图：更容易比较、更现代、手机更友好。标签直接写百分比，并在页脚注明这是叙事构成值而非概率。

## F 觉醒轨迹

横向成长轴，四段状态各有独立文案。可与主神格的 `states` 字段一一对应，当前状态由主神格匹配强度与 shadow 强度共同决定（具体阈值在 Phase 3 校定）。

## G 人格星图

把维度聚合为 Mind / Will / Order / Desire / Social / Shadow / Transcendence 形成星座。节点大小 = 强度，透明度 = 置信度，边 = 维度关系。主要用于美学传播，不使用精确数值标签。

## H 人格张力矩阵

双极条（Freedom ↔ Control、Chaos ↔ Order、Instinct ↔ Reason、Preserve ↔ Create、Present ↔ Future）。手机端理解成本低于雷达图，因此结果页同时保留雷达图与张力条。

## 跨模块约定

- 调色统一走 `src/theme.ts`：4 个谱系角色各有固定颜色，雷达、构成条、轨道图、分享卡使用同一套 ——
  `you/primary #e8c98a` · `secondary #b9a7f0` · `shadow #8d7fb8` · `hidden #5fc9b6`。
  读者看两次就能记住「紫色=副神格、青绿=隐藏」，不需要图例反复解释。组件里不再出现散落的十六进制色值。
- 每张图必须有文本替代（`<figcaption>` 或维度数值列表），且关键差异不能只靠颜色区分。
- 图表数据一律来自 result 对象，图表组件不接触原始答案或神格库。

## 移动端与可访问性（实现细节）

- 结果页顶部是**吸顶导航**（谱系 / 构成 / 图谱 / 主神格 / 内战 / 觉醒 / 分享）。因为 hash 路由占用了 `#/…`，导航用 `scrollIntoView()` 而不是锚点链接，避免点一下导航就切走页面。
- 长报告段落用原生 `<details>` 折叠，主神格一节默认展开；这比自写折叠组件少一半代码，还自带键盘与读屏支持。
- 雷达图旁提供可展开的「查看数值」表格：负向词 / 你的值 / 正向词。信息不再只存在于图形里。
- 全站 `:focus-visible` 金色描边；选项按钮高度 ≥ 48px；`prefers-reduced-motion` 下关闭动画。
- 分享卡支持 4:5（1080×1350）与 1:1（1080×1080），排版按高度比例计算，切尺寸不需要重新手调。
